# GrassQuest 🌿

GrassQuest is a mobile-first web app that gives you one small outdoor quest per day — like "find three different leaf shapes" or "spot a bird on a fence." It picks the quest based on your local weather and mood, then uses a local open-weight AI model (Gemma via Ollama) to verify your photo. Earn XP, build streaks, and collect badges — all while getting outside more.
